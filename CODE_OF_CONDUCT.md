# Community Code of Conduct

Be respectful, constructive and welcoming to people of all backgrounds and
experience levels. Review code and ideas rather than attacking people.

Harassment, threats, discrimination, sexualized behavior, spam, publishing
private information, and persistent disruption are unacceptable in issues,
pull requests and other project spaces.

Maintainers may edit or remove inappropriate contributions, lock discussions,
or temporarily or permanently restrict participation. Decisions should be
proportionate, explainable and applied consistently.

Report concerns privately to the maintainer through the contact method on the
maintainer's GitHub profile. Do not publish sensitive allegations or personal
data in a public issue. Reports are handled as confidentially as practical.
