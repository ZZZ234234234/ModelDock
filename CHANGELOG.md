# Changelog

## 1.0.0 — 2026-09-05

Initial web release.

- Chinese-first dark and light workspace with ten application routes.
- Eleven provider presets, custom providers and three API wire formats.
- Real model catalog requests, editable models and local-server detection.
- Streaming chat, stop, retry, prompt editing and saved conversations.
- Concurrent comparison of up to four models; separate TTFT and total latency.
- Experimental anonymous AI Judge with shuffled candidates and validated scores.
- Playground controls, raw request/response inspection and three code exports.
- Local request history, usage charts, provider/model/date filters and CSV export.
- Session-only API keys; optional password-encrypted browser vault.
- Opt-in stateless relay restricted to official provider endpoints.
- Clearly labeled local demo mode; no real API keys required.

### Boundaries

Text-only APIs; no desktop installer, cloud synchronization or team workspace.
Provider adapters are protocol-tested; paid-provider access requires the user's
own valid key and model entitlement. Catalog endpoints may be unavailable or
return non-chat models. Prices are user supplied. Estimates are not invoices.
